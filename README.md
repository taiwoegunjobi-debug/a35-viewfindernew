# A35 Anamorphic Viewfinder

Simplified Pixel 6 Pro landscape PWA for ALEXA 35 anamorphic framing.

Controls:
- START CAMERA
- FLIP
- Lens buttons: 28, 35, 40, 50, 60, 75, 100, 135, 180mm
- PHOTO

The app simulates ALEXA 35 Super 35 horizontal framing using the Pixel main-camera field of view and applies a crop/zoom estimate for each Master Anamorphic lens.

Camera access requires HTTPS. Deploy the folder to Vercel and install from Chrome on Android.

This is a framing/reference tool, not an optical replacement for a physical ALEXA 35 and anamorphic lens.
