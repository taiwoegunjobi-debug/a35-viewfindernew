# A35 Lens Finder V3

Minimal ALEXA 35 anamorphic framing finder for Pixel 6 Pro landscape.

This version deliberately uses a simple getUserMedia camera startup with a rear-camera preference and a fallback to any camera. It does not call screen.orientation.lock during startup.

Lens set: 28, 35, 40, 50, 60, 75, 100, 135, 180mm.

Deploy over HTTPS (Vercel). Open in Chrome on the Pixel 6 Pro.
