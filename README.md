# A35 Lens Finder

Minimal landscape viewfinder for Google Pixel 6 Pro.

## Interface
- Full-screen rear camera
- ALEXA 35 / Super 35 2.39:1 monitoring frame
- ARRI/ZEISS Master Anamorphic lens set:
  28, 35, 40, 50, 60, 75, 100, 135, 180mm
- One-tap lens selection
- Lens-specific framing crop based on horizontal field of view
- 2x anamorphic label
- One large PHOTO button
- Rear/front camera flip removed from main interface
- Landscape orientation request
- Clean reference-photo capture

## Deploy
Upload all four files to GitHub and deploy with Vercel. Open the HTTPS Vercel address in Chrome on the Pixel 6 Pro. Install the site from Chrome's menu.

## Note
This is a framing finder, not an optical emulation of an ALEXA 35 and physical anamorphic lenses. The crop is based on published/working horizontal AOV reference values and an approximate Pixel 6 Pro main-camera horizontal FOV. Exact optical characteristics such as distortion, bokeh, flare, breathing and focus rendering cannot be reproduced by a browser camera.
